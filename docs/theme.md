# 配色与样式

内容只用黑 / 白 / 灰，蓝（`#2563eb`）是唯一的主题色：主要操作用它，选中态用它，
运行时的信号流光也用它。字体只自带一款 Azeret Mono（拉丁与数字，等宽，数字能对齐），
中文走系统回退。

所有 token 都在 `src/styles/app.css` 开头那一段 —— 换配色只改那里，不用翻每个组件。

## 同一套表面

节点卡片、节点库、各种浮层共用同一套表面：**白底、发丝边、同一个圆角、同一个阴影**，
所以整屏看起来是一件东西。

## 类型颜色

类型颜色也收在蓝灰这条梯度上：

| 类型 | 颜色 |
| --- | --- |
| 具体格式的图像 | 蓝 |
| 格式未知的图像 / `Any` | 灰 |
| 文本 / 数字 / 布尔 | 灰 |

「到底是 PNG 还是 JPG」由徽标上的**字**说，不靠颜色猜 —— 十种格式各占一个色相，在
这么小的徽标上也分不出来。表在 `src/lib/ports.ts`。

## 组件层

组件用 [Radix UI](https://www.radix-ui.com/) 的原语：行为（键盘导航、焦点管理、弹层
定位、可访问性）交给它，**外观全部由 `src/styles/app.css` 里那套 CSS 变量决定**。

这样选的原因是节点那层（纸片卡片、端口、连线）本来就不该由组件库决定；能外包的只有
外壳，而外壳外包之后风格依然是同一套 token 出来的。

有几个坑值得记一笔，它们都只在屏幕上看得出来：

- **开放 SVG 路径默认会被填成黑色。** 连线必须是 `fill: none`，断开动画里那两条自己画的
  路径也要显式写 —— 不写的话，曲线和弦围出来的那块会被填实。
- **开关的圆点只写静态 `transform` 是不够的。** 少了「打开时挪到另一头」那条规则，
  看着就像没有动画。
- **下拉项不能用 `grid-template-columns` 按位置分列。** Radix 的选中标记没选中时渲染
  `null`，按位置分列会让文字竖排；得用 flex + 一个常驻的占位格。

上面几条都有测试守着（`src/graph/WireEdge.test.tsx`、`src/graph/ParamField.test.tsx`、
`src/panels/Chrome.test.tsx`）。
