# 界面与交互

整个应用就是一张画布（浅灰底，无限延伸）。背景那层浅灰小点由 `Canvas.tsx` 的
`SHOW_DOT_BACKGROUND` 开关控制 —— 现在**关着**（在查拖动卡顿，见
[开发](development.md#拖动那条热路径)）。其余东西都浮动在它上面：

| 位置 | 是什么 |
| --- | --- |
| 左上 | 工作流名、说明与概要、**节点库** |
| 右上 | **加载**已保存的工作流、保存、**运行** |
| 左下 | 缩放控件 |
| 底部中间 | 状态药丸，跑完点开是运行记录 |

边栏不存在 —— 按钮就是几个圆角矩形，直接排在画布上，没有外面那层胶囊壳。

改名写在左上角的输入框里，说明写在它右边的按钮里，两者紧挨着；右上角那组按钮下面有
一个未保存的小蓝点，像给「保存」加的标注。右上角那个只负责**加载**存档，不管填写。

## 节点库

点「节点库」会从按钮**下面**展开一个浮动窗口：左栏是分类，右栏是工具卡片
（名称 + 一句话说明 + 输入输出类型标注）。列表长了、或者上面展开着一张卡片，就在框内滚动。

- **点一下卡片**：向上浮起展开，列出注意事项、参数说明和端口；再点别处收回。
- **按住卡片拖出去**：直接落到画布上。被拖走的那张卡片会被一个「向外」的箭头盖住，
  同时一枚显示节点名的胶囊吸附在指针上，落下时有一段入场动画。

节点库按钮在左上角标题下方、朝下展开，这样展开时不挡视线。

## 右键划刀

在画布**空白处**按住右键滑动，会划出一道刀光。被刀光扫到的连线会亮成红色，表示
「将被删除」；松开右键，刀光向前跟出并消散，被切中的连线从断口向两端缩回去、断口闪
一下，然后真的从图里消失。按 Esc、或者鼠标松开在窗口外，都会取消这一刀。

判交拿的是连线上**实际渲染出来的那条贝塞尔路径**（采样成折线），不是另算一遍的近似
曲线，所以看上去碰到的就是碰到的。这部分几何在 `src/lib/geometry.ts` 里，是纯函数，
有测试盯着。

右键落在节点或连线上时不起刀 —— 那些地方该弹原生菜单。

## 参数控件

节点卡片上的参数是直接改的。几种控件都来自 `src/ui/`：

| 参数种类 | 控件 |
| --- | --- |
| 数字 | 单行输入框，带单位后缀 |
| 滑杆 | 一根滑杆 + 右侧读数 |
| 文本 | 单行 / 多行输入框 |
| 下拉 | 自制列表盒（原生 `<select>` 的弹层没法做样式） |
| 开关 | 拨动开关，右边带「开 / 关」 |
| 文件 / 目录 | 空着是虚线框按钮，选完文件名顶在按钮的位置，鼠标移上去露出重选的按钮 |

参数可以**跟着别的参数取值**决定显不显示（后端在元数据里写 `visibleWhen`，支持
「或」和「而且」两种条件），例如「图像压缩」的「颜色数上限」只在
**有损 + PNG 调色板**时才出现。判断在前端 `src/lib/params.ts` 里，这样卡片上的变化是
即时的，不用等一次 IPC 往返。

控件都带 `nodrag`（多行文本框还带 `nowheel`）：React Flow 只在节点内部找 `nodrag`
这个类，少了它，在控件上按下鼠标就会开始拖节点。
