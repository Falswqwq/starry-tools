# 读取

**id** `read` · **分类** 来源 · **起点节点**（没有输入端口）

从硬盘上读一个文件：「类型」参数说这个文件是什么 —— **图像文件**按图像解码，
**文本文件**按 UTF-8 文本读进来，**视频文件**（启用视频功能时）读成视频产物。
一个工作流可以放多个读取节点，让几条支线各走各的。新建工作流时已经带一个。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输出 | `out` 值 | **自动推断**：`TEXT` / `IMG`（具体格式）/ `VID`（具体格式），待定时是 `ANY` |

| 选的是 | 输出端口的类型 |
| --- | --- |
| 图像文件 | `PNG` / `JPEG` / … —— 按**文件头**的真实格式 |
| 图像文件（还没选文件） | `ANY`（待定）—— 节点库卡片上看到的就是它 |
| 文本文件 | `TEXT` |
| 视频文件 | `MP4` / `MKV` / … —— 按扩展名猜 |
| 视频文件（还没选文件） | `VID`（待定） |

## 参数

| 参数 | 控件 | 默认 | 何时显示 |
| --- | --- | --- | --- |
| 类型 | 下拉 | 图像文件 | 总是 |
| 图像文件 | 文件选择 | 空 | 类型 = 图像文件 |
| 文本文件 | 文件选择 | 空 | 类型 = 文本文件 |
| 视频文件 | 文件选择 | 空 | 类型 = 视频文件（启用视频功能时） |

图像文件框过滤十种可解码的格式（PNG / JPEG / GIF / WebP / BMP / TIFF / ICO / QOI /
TGA / PNM）；文本文件框过滤常见的文本扩展名；视频文件框过滤主流容器
（MP4 / MKV / WEBM / MOV / AVI）。选完图像之后节点上会显示缩略图、尺寸、格式和体积。

## 行为约定

- 输出类型**自动推断**：选了 JPEG，输出就是 `JPEG`，下游的类型检查因此在编辑期
  就是准的；选文本文件就是 `TEXT`，选视频就是对应的视频类型。
- 还没选文件时输出 `ANY`（待定），编辑期可以接到任何端口上。
- **没有「数字」这一档** —— 从一个文件里读一个数太拧巴了；要给一个数字，直接用
  [数字](literal_number.md)字面量节点。
- **工作流里只记路径，不会把文件内容一起存下来。** 文件挪走之后要重新选一次。
- 没选文件就跑会直接失败：`还没有选择图像文件` / `还没有选择文本文件` / `还没有选择视频文件`。
- 视频只按**扩展名**判容器格式，不会把整个文件读进内存。
