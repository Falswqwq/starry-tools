# 背景移除

**id** `background_removal` · **分类** 图像

用 AI 模型**认出主体**、把背景抠成透明。比「颜色剔除」聪明得多：不是按颜色抠，而是理解
画面里什么是主体，所以头发丝、半透明的纱、和背景同色的部分都能保住。

模型**不带在应用里**（u2net 那几个最小也有几个 MB）。第一次用要先下载 —— 没下载时这个
节点在画布上是**禁用**的，卡片上挂一块「下载模型」面板。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` 图像 | `Image(Any)`（必填） |
| 输出 | `image` PNG 图像 | `Image(Png)` |

输入不锁格式，输出一定是 PNG（要带透明通道）。

## 参数

| 参数 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 模型 | 下拉 | U²-Netp | 用哪个模型；选项带着「小、快 / 更大更准」的短说明 |

「模型」是一个普通的下拉框，所以它**本身**也能被上游喂（虽然很少这么用）。节点缺模型时，
它是整个节点里**唯一还活着的**控件 —— 用户正是靠它挑要下哪个模型。

## 缺模型时会发生什么

模型文件放在 `<数据目录>/models/` 下。某台机器上还没有对应文件时：

- 节点边线变成**琥珀色**、加粗一档，标题右边标一个「需模型」；
- 除「模型」下拉框外，所有参数控件都是**禁用态**（灰下去、点不动）；
- 卡片底部的「运行至此」不生效；
- 参数区下面多出一块**琥珀色面板**：模型名 + 大小 + 一句说明 + **源下拉** + **下载按钮**。

点「下载模型」就在后台线程下到 `<数据目录>/models/`，面板上的按钮这时变成一条**进度条**
（鼠标移上去显示「取消下载」，点一下就取消）。下完了这一项消失，节点下一帧自动恢复成能跑
的状态。下载失败会在面板第二行显示原因（红色），按钮变成「重试下载」。

**下载源可选**：每个模型给了**原始源**和**镜像源**两个入口（下拉框里挑）。国内直连 GitHub
的 release 常常超时，镜像源（hf-mirror）快得多，所以 u2net 默认把镜像源放在前面。

## 行为约定

- 下载**先写 `*.onnx.part`，成功了再改名为正式文件** —— 中途断了不会留下半截文件被误当成
  「已下载」。
- 正在下载时源下拉框**锁住**，免得下半道换源。
- 运行的时候如果模型仍然不在（比如手动把文件删了），节点会报一句「模型「X」还没下载 ——
  在卡片上点「下载模型」」，而不是静默什么都不干。
- 结果一律是 PNG：RGB 保持原样，alpha 换成模型的遮罩值，来源文件名接着带下去。

## 实现

分两块：

- `core/src/bg_model.rs` —— 模型清单（`MODELS`：id / 名字 / 文件名 / 大小 / 一句说明 /
  下载源）、本地路径（`path_for` / `is_downloaded`）、下载（`download`，支持取消与进度回调）
  和删除（`remove`）。界面不认识具体模型，只读这份清单。
- `core/src/rembg.rs` —— 推理。这里是 rembg 那条流水线的 Rust 版：把图缩到 320×320、
  按 ImageNet 的均值方差归一化、喂给模型，再把模型吐出来的遮罩缩回原尺寸当 alpha。
  用 [`tract-onnx`](https://github.com/sonos/tract) 纯 Rust 推理 —— 不需要 onnxruntime 那种
  原生动态库。没开 `onnx` 特性时（`--no-default-features`）它是个会报错的桩。

参考实现：[kirinonakar/rust_rmbg](https://github.com/kirinonakar/rust_rmbg)（同样的
tract + u2net 思路）。

边界处理：

- 遮罩做 **min-max 归一化**回 0–1（模型输出不一定在范围内）；遮罩整个是一个常数时
  （全 0 / 全 1）不拉伸，直接按它本身取 —— 否则全 1 会被算成全透明。
- 模型的 `Resize` 节点用的是 `pytorch_half_pixel` 模式，需要 `tract-onnx ≥ 0.23`。

测试：

- `rembg::tests::the_mask_becomes_the_alpha`（不依赖模型：全 0 遮罩 → 全透明、全 1 → 全保留、
  RGB 不动）；
- `rembg::tests::smoke_real_model`（`#[ignore]`，本机有模型时才真跑一遍推理）；
- `bg_model::tests::*`（清单 / 路径 / 未知 id）。
