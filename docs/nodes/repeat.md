# 重复执行

**id** `repeat` · **分类** 逻辑

把接在「循环体」上的分支按指定次数重复执行。每轮从「索引」输出当前序号（0 起），
全部成功后走「结束」。分支失败会停止后续轮次，不再触发结束。

## 端口

| 方向 | 端口 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `exec` | Exec | 由执行线触发 |
| 输出 | `body` 循环体 | Exec | 每轮触发一次 |
| 输出 | `index` 索引 | `NUMBER` | 当前轮次，从 0 开始 |
| 输出 | `finally` 结束 | Exec | 全部轮次成功后触发 |

## 参数

| 控件 | 默认 | 范围 |
| --- | --- | --- |
| 次数 | 3 | 0–10000，整数 |

填 0 时跳过循环体，直接走「结束」。

## 行为约定

- 同步执行：每轮循环体及其整个下游分支完成后，才开始下一轮。
- 每轮的数据帧互相隔离；`index` 离开该轮后不可再被下游消费。
- 循环内的数据产物写盘时，文件名会带上轮次路径，避免互相覆盖。
- 需要按列表逐个处理时用[遍历](iterate.md)；需要固定次数时用本节点。
