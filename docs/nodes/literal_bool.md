# 布尔

**id** `literal_bool` · **分类** 变量 · **纯数据节点**（深绿色边线）

保存一个开关值。参数中的值是本次运行的初始值；Get 在需要时读取当前值，Set 可由多个上游写入。
成功运行后最终值写回参数，下一次运行从这里继续。

## 端口

| 方向 | 端口 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `set` Set | `BOOL` | 允许接多条线，按上游实际运行的先后写入 |
| 输出 | `out` Get | `BOOL` | 可同时接多个下游 |

没有执行引脚。Set 不参与 Get 的求值依赖，写入先影响本次运行中的后续读取；
成功后写回参数，失败不提交。详见[变量节点](../variables.md)。
