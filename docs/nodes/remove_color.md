# 颜色剔除

**id** `remove_color` · **分类** 图像

把跟目标色相近的像素抠成透明 —— 去底色、做色键（chroma key）都靠它。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` 图像 | `Image(Any)`（必填） |
| 输出 | `image` PNG 图像 | `Image(Png)` |

输入不锁格式（`Image(Any)`）—— 去底色的场合很多，没必要逼着先转 PNG。
输出一定是 PNG，因为要带透明通道。

## 参数

| 参数 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 模式 | 下拉 | 全图剔除 | 全图 / 背景 |
| 目标色 | 取色器 | `#ffffff`（白） | 要被抠掉的颜色；可接色板（取第一个色） |
| 相近色剔除阈值 | 数字 0–255 | 16 | 每个分量差在这个范围内的都一起剔 |

## 两种模式

| 模式 | 做什么 | 什么时候用 |
| --- | --- | --- |
| **全图剔除** | 只要颜色像就剔，不管在哪儿 | 这个颜色本来就是错的 |
| **背景剔除** | 只剔**与画面外圈相连**的像素 | 去底色（推荐） |

## 行为约定

- 相近的判定是**逐分量**的最大差值：`|ΔR|`、`|ΔG|`、`|ΔB|` 都不超过阈值就算同一种。
  阈值 0 只剔颜色完全一样的像素。
- **只改 alpha**：被剔的像素变成全透明，RGB 一个字节不动；本来就透明的像素不受影响。
- 目标色是透明的时候没有东西可剔，原样通过并提示。
- 一个像素都没命中的话也提示一句，免得以为节点没生效。

### 背景剔除的智能处理

背景剔除从画面**外圈**发起一次洪水填充，沿着「像目标色」的像素往里漫延，所以：

- **被主体包住的同类颜色不会被抠掉** —— 比如白底 sprite 里白色的眼睛、白衬衫上的白扣子，
  它们挨不到外圈，就留下来了。
- 用的是 **4 连通**，不是 8 连通：八邻接会让填充从对角的一条单像素缝里钻进去，把本该
  留住的东西抹掉。
- **已经透明的像素也算背景** —— 填充能穿过透明边距继续往里去。
- **边缘羽化**：紧贴着背景、颜色又「差一点点」的过渡像素（距离在 `阈值`、`阈值 + 24`
  之间）会按接近程度调成半透明，去处抗锯齿留下的一圈底色杂边。主体色离目标色远的话
  完全不受影响。

## 和「色彩分析」搭起来用

目标色可以接上游的色板（`Color` 参数的输入端口是 `Text`，取第一个颜色）。所以：

```
读取 → 色彩分析（数量统计）→ 颜色剔除「目标色」
```

就能自动把画面里出现最多的那个颜色抠掉，不用手填 hex。
