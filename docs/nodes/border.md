# 边框/边距

**id** `border_image` · **分类** 图像

给图像加一圈边框。关键是**沿着内容描边，而不是沿着画布**。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` PNG 图像 | `Image(Png)`（必填） |
| 输出 | `image` PNG 图像 | `Image(Png)` |

输入输出都锁在 PNG，和别的图像节点一样。

## 参数

| 参数 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 粗细 | 数字 0–256 px | 1 | 边框宽度，0 就是什么都不做 |
| 颜色 | 取色器 | `#000000`（黑） | 收起时是一条色条，点开取色；可接色板（取第一个色） |

「颜色」用的是**通用取色器控件**（`ParamSpec::Color`）—— 收起时是一条圆角色条
（半透明的颜色透出浅灰底，全透明时画斜杠），点开是取色区（x = 饱和度，y = 亮度）
+ 色相条 + R/G/B + Hex + 不透明度。值是个字符串：不透明 `#rrggbb`、带透明度
`#rrggbbaa`；`transparent` 也是全透明。以后任何节点想要个颜色，声明一个 `Color` 参数就行。

它的输入端口是 `Text`，可以接[色板](palette.md)过来 —— 那时取**第一个颜色**。

## 行为约定

- **描边认的是 alpha**：`alpha != 0` 的像素算「内容」，边框画在内容之外。
- **整张不透明**（没有任何透明像素）时，内容就是整张画布，于是四边各扩 `粗细` 像素、
  新边距填上颜色 —— 就是一个画框。
- **有透明像素**时描的是非透明像素的边界：把内容向外膨胀 `粗细` 像素，膨胀出来、
  原本全透明的像素涂上颜色。
- **透明的洞**（甜甜圈形的 sprite）会从内侧被描上 —— 洞四周的实体同样向洞里膨胀。
- 画布**只在需要时才扩**：某一侧的内容离边不到 `粗细`，描边会被切掉，那一侧才补出来。
  内容本来就在画布里头的话尺寸不变 —— 游戏素材的一帧不会被无辜地改大小。
- 颜色挑**透明**时就只加边距、不画颜色；粗细为 0 或整张图透明时原样通过并提示。
- 只涂**完全透明**（alpha == 0）的像素，不去覆盖边缘的半透明像素。

## 实现

`core/src/nodes/border.rs`，`NodeSpec::fixed`。

流程：解码成 RGBA → 求内容外接矩形、算出四边需要补多少 → 把内容整块搬进新画布
→ 在新画布上做一次 **chamfer 距离变换**（两遍扫描，权重 1 / √2，O(像素数)），得到
每个像素到最近内容的近似距离 → 把距离 ≤ `粗细 + 0.5` 的透明像素涂成边框色。

用距离变换而不是逐像素扫一个 `(2t+1)²` 的窗口，粗细再大也是 O(像素数)。

测试：`border_grows_an_opaque_image_into_a_frame`（不透明图加画框）、
`border_outlines_transparent_content_in_place`（有留白的 sprite 尺寸不变、描内容边界）、
`border_outlines_the_inside_of_a_hole`（甜甜圈的内侧也被描上）、
`border_with_a_transparent_colour_just_pads`（透明色 = 纯加边距）、
`colors_parse`（颜色字符串解析与坏值回落）。
