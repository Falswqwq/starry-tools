# 遍历

**id** `iterate` · **分类** 逻辑

对列表逐项串行执行循环体。执行与数据分开连接：

| 方向 | 端口 | 类别 / 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `exec` | Exec | 触发遍历 |
| 输入 | `list` 列表 | Data `List[Any]` | 必填 |
| 输出 | `body` 循环体 | Exec | 每项触发一次，等待整个循环体完成 |
| 输出 | `item` 元素 | Data `ANY` | 当前项，不触发执行；运行时严格校验类型 |
| 输出 | `finally` 结束 | Exec | completed：全部成功后触发，空列表也触发 |

`finally` 是完成端口的兼容 id，**不是异常清理**；循环体失败会停止后续轮次，也不触发完成路径。
「最大遍历数目」默认 0，表示遍历全部；大于 0 时最多处理指定数量。

例如：Exec 接 `起点 → 读取目录 → 遍历`、`body → 缩放图像`；
Data 另接 `读取目录.out → list`、`item → 缩放图像的图像输入`。
收尾节点接 `finally`。

循环可以嵌套，内层能读取外层 item。数据连线不会扩大循环作用域；循环体产物离开该帧后不可消费，
跨循环传值请使用[变量节点](../variables.md)。变量状态不随循环帧恢复而回滚。
固定次数的循环用[重复执行](repeat.md)。
产物名包含轮次路径以避免覆盖；运行报告保留每次触发记录，同一节点可出现多次。
