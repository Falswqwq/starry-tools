# 视频压缩

**id** `video_compress` · **分类** 视频

用外部 `ffmpeg` 把视频重新编码压小。输入收下常见的视频格式，输出容器由「输出格式」决定。

> 需要本机装有 `ffmpeg` 与 `ffprobe`（都在 `PATH` 里）。找不到时，节点会像「背景移除」
> 缺模型那样**整个禁用并挂一句提示**（边框变警示色、右上角写「需 ffmpeg」），运行也会直接报错。
> 视频功能由核心的 `video` cargo feature 开关，默认开启。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `video` 视频 | `VID`（必填） |
| 输出 | `video` 视频 | **动态**：跟着「输出格式」变成 `MP4` / `MKV` / `WEBM` / `MOV` / `AVI` |

## 参数

| 参数 | 控件 | 默认 | 何时显示 |
| --- | --- | --- | --- |
| 压缩预设 | 下拉 | 平衡 | 总是 |
| 输出格式 | 下拉 | MP4 | 总是 |
| 保留原始分辨率 | 开关 | 开 | 预设 = 自动 |
| 编码器 | 下拉 | 自动 | 预设 = 高级 |
| 质量（CRF） | 滑块 | 23 | 预设 = 高级 |
| 编码速度 | 下拉 | 中 | 预设 = 高级 |
| 自适应量化（AQ） | 下拉 | 自动 | 预设 = 高级 |
| 分辨率上限 | 下拉 | 保持原始 | 预设 = 高级 |
| 音频码率 | 下拉 | 128 kbps | 预设 = 高级 |

## 四个预设

| 预设 | 做什么 |
| --- | --- |
| **平衡** | 参数均衡、跑得快、兼容性最好（H.264，CRF 23，preset medium）。 |
| **激进** | 目标是把体积压到最小、肉眼尽量无损：换更高效的编码器 **H.265**（WebM 里用 VP9），配慢 preset + 方差 AQ + 对应编码器的 CRF。**一定比「平衡」更小。** |
| **自动** | 先 `ffprobe` 探一遍输入（分辨率、帧率、时长），再抽几帧估一下是不是动画 / 像素风，据此自动挑编码器、CRF、preset，以及要不要降分辨率。 |
| **高级** | 把各参数摊开来手动调，默认值就是「平衡」那一套。 |

## 「自动」怎么判断

- **编码器**：按分辨率选 —— ≤1080p 用 H.264（兼容），≤1440p 用 H.265，更高用 AV1。
- **动画判断**：从视频抽几帧缩到 48×48，统计相邻像素相同的比例（平坦度）。赛璐璐动画 /
  像素画大片平色，平坦度显著更高。是动画就允许更狠的量化（CRF +2）、并用更慢的 preset。
- **降分辨率**：只有关掉「保留原始分辨率」、且源高超过 1080 时才降到 1080p。

这是**启发式**的，判错了手动切「高级」即可。

## 运行时看见什么

- **进度条 + 帧计数**：编码时，卡片**下方的信息区**会长出一块：左边「帧 12/300」、
  右边「35% · 24 帧/s」（百分比 · 编码速度），下面一条**“胶片”进度条** —— 实心蓝条里
  一条条细纹随进度向右流动，前沿一道细亮线（纯色细线，不用渐变、也没有圆点）。
  动画落在**条身**上，所以进度一时不动时它看着也是活的。总帧数从 `ffprobe` 拿
  （`nb_frames`，没有就用时长 × 帧率估）；两者都没有时进度条走**不确定态**（整块胶片
  在轨道上来回扫）。跑完这块会换成结果提示。
- **大小变化与压缩率**：跑完会报一声 `原 → 压后（压到 N%）`，产物摘要里也带了
  「原大小」与「压缩率」。**压完反而变大时**会警告一句（输入可能已经压得很紧）。

## 行为约定

- 输入输出都走**临时文件**（ffmpeg 对某些容器需要可回退的输入，管道不可靠），
  跑完就删。
- 进度用 ffmpeg 的 `-progress pipe:1` 解析，和界面帧率无关。
- ffmpeg 失败时，把 stderr 的最后几行原样报出来，方便定位。
- 重编码总会掉一点画质 —— 想完全无损请换个思路（保留原编码，只改容器）。
