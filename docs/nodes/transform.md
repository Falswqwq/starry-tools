# 图像变换

**id** `transform_image` · **分类** 图像

只做几何变换、不碰颜色：翻转（左右 / 上下）、旋转（90° / 180° / 270°），
或按长宽比例分别拉伸。翻转 / 旋转逐像素搬运，PNG 转 PNG 无损；拉伸使用邻近采样。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` PNG 图像 | `PNG`（必填） |
| 输出 | `image` PNG 图像 | `PNG` |

输入输出都锁在 PNG，和「缩放图像」「图像裁切」一样 —— 要改用别的格式先接一个
「图像格式转换」。

## 参数

| 参数 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 处理方式 | 下拉 | 翻转 / 旋转 | 翻转 / 旋转 或 图像拉伸 |
| 左右翻转 | 开关 | 关 | 沿竖轴镜像（翻转模式） |
| 上下翻转 | 开关 | 关 | 沿横轴镜像（翻转模式） |
| 旋转 | 下拉 | 不旋转 | 不旋转 / 顺时针 90° / 180° / 顺时针 270°（翻转模式） |
| 宽度拉伸 | 数字，% | 100 | 1–1600%，100% 表示宽度不变（拉伸模式） |
| 高度拉伸 | 数字，% | 100 | 1–1600%，100% 表示高度不变（拉伸模式） |

## 行为约定

- **翻转 / 旋转**：顺序是先翻转、后旋转（两者不交换）。例如「左右翻转 + 顺时针 90°」
  会先水平镜像，再把结果转过去。90° / 270° 会让宽高对调；180° 不改变尺寸。
- **翻转 / 旋转**：三个参数都是默认值（不翻不转）时原样通过，并提示一句。
- **图像拉伸**：宽度和高度独立计算，目标尺寸为原尺寸乘以对应百分比后四舍五入，
  最小 1 像素。小于 100% 是压缩，大于 100% 是放大；某一方向为 100% 时该方向保持不变。
- 拉伸两个方向都是 100% 时原样通过并提示。
- 拉伸使用邻近采样，不混出新颜色，适合像素画；超过 6400 万像素会报错。
