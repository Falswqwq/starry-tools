# 图像变换

**id** `transform_image` · **分类** 图像

只做几何变换、不碰颜色：翻转（左右 / 上下）与旋转（90° / 180° / 270°）。
像素是一个一个搬过去的，所以 PNG 转 PNG 是无损的。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` PNG 图像 | `Image(Png)`（必填） |
| 输出 | `image` PNG 图像 | `Image(Png)` |

输入输出都锁在 PNG，和「缩放图像」「图像裁切」一样 —— 要改用别的格式先接一个
「图像格式转换」。

## 参数

| 参数 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 左右翻转 | 开关 | 关 | 沿竖轴镜像 |
| 上下翻转 | 开关 | 关 | 沿横轴镜像 |
| 旋转 | 下拉 | 不旋转 | 不旋转 / 顺时针 90° / 180° / 顺时针 270° |

## 行为约定

- 顺序是**先翻转、后旋转**（两者不交换）。例如「左右翻转 + 顺时针 90°」会先水平镜像，
  再把结果转过去。
- 90° / 270° 会让宽高对调；180° 不改变尺寸。
- 三个参数都是默认值（不翻不转）时**原样通过**，并提示一句。
- 纯几何变换，像素一个不少、颜色一点不改，所以不会引入任何有损误差。
