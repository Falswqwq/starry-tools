# 缩放图像

**id** `upscale` · **分类** 图像

把 PNG 图像缩放到原来的百分之 n。像素画常配「邻近」插值做整数倍放大 —— 放大后每个
像素还是干净的方块。

> id 保留 `upscale` 没改（显示名从「放大图像」改成了「缩放图像」）：它写在存档里，
> 改了老工作流就打不开了。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` PNG 图像 | `Image(Png)`（必填） |
| 输出 | `image` PNG 图像 | `Image(Png)` |

输入输出都锁在 PNG：想把 JPEG 缩放，得先接一个「图像格式转换」。
**这正是类型系统存在的意义 —— 连线的时候就知道这一步过不去。**

## 参数

| 参数 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 缩放比例 | 数字 1–1600 % | 200 | 100% 是原始大小，整数倍放大就填 200 / 300 / 400 |
| 插值算法 | 下拉 | 邻近 | 见下 |

| 插值 | 适用 |
| --- | --- |
| 邻近 | 像素画首选，边缘保持硬朗 |
| 线性 | 一般用途 |
| Catmull-Rom | 更平滑，略带锐化 |
| 高斯 | 最柔和 |
| Lanczos3 | 照片放大最锐利，代价是硬边缘旁边会有轻微光晕 |

## 行为约定

- 输出尺寸 = 原尺寸 × 比例 ÷ 100，四舍五入到整数像素。100% 就是原样通过（会提示一句）。
- 比例小于 100% 时实际上是在缩小，同样会提示。
- **输出像素总数超过 6400 万会直接报错**，免得手滑填个大数字把内存吃光。

## 实现

`core/src/nodes/upscale.rs`，`NodeSpec::fixed`。解码 → `resize_exact` → 编 PNG，
插值算法映射到 `image::imageops::FilterType`。上限是文件里的 `MAX_OUTPUT_PIXELS`。

测试：`engine::tests::upscale_keeps_pixels_crisp_with_nearest_neighbour` ——
用最近邻放大 400%，逐像素确认每个原像素变成一个 4×4 的纯色方块，中间不出现过渡色。
