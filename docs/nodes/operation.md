# 运算

**id** `operation` · **分类** 变量

对两个对象做基本运算。运算方式决定端口类型：数值运算（加 / 减 / 乘 / 除 / 取余 / 取整）
要两个 `NUMBER`，输出 `NUMBER`；「字符串拼接」要两个 `TEXT`，输出 `TEXT`。

## 端口

| 方向 | 端口 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `exec` 执行 | Exec | 由执行线触发 |
| 输入 | `a` A | `NUMBER` / `TEXT` | 必填，左操作数 |
| 输入 | `b` B | `NUMBER` / `TEXT` | 必填，右操作数 |
| 输出 | `out` 结果 | `NUMBER` / `TEXT` | |
| 输出 | `then` 继续 | Exec | 运算成功后继续执行 |

切到「字符串拼接」时，这三个端口会一起变成 `TEXT`；切回数值运算再变回 `NUMBER`。

## 参数

| 控件 | 默认 | 选项 |
| --- | --- | --- |
| 运算 | 加 | 加 / 减 / 乘 / 除 / 取余 / 取整 / 字符串拼接 |

- **加 / 减 / 乘 / 除**：`A + B`、`A − B`、`A × B`、`A ÷ B`（浮点）。
- **取余**：`A % B`（余数的符号跟 `A`）。
- **取整**：`A ÷ B` 的整数部分（向零截断）。
- **字符串拼接**：`A` 后直接接 `B`，不插入分隔符。

## 行为约定

- 两个输入都是**必填**的 —— 它们就是运算的两个对象；缺一个就报错。
- 除数为 0 时节点失败，错误信息是「除数不能为 0」，不会产出无穷大 / `NaN`。
- 端口类型由运算方式现算，所以编辑期就能挡住「把文本接到数值运算上」这类连线。
- 数值结果是 `f64`；整数在界面上显示成 `10` 而不是 `10.0`。
- 运算是显式调度节点：必须由 Exec 触发，成功后沿 `then` 继续；不再作为纯表达式被数据线隐式拉取。
- 累加把变量 Get → 运算 → 变量 Set 接成数据线，并让运算位于执行线上；Set 不构成运算的求值依赖，因此不会成环。
