# 顺序执行

**id** `sequence` · **分类** 逻辑

按数字序号执行 `out1` 到 `outN`：前一个输出的**整个分支**（包括嵌套控制流）
执行完成后才开始下一分支。

| 方向 | 端口 | 类别 |
| --- | --- | --- |
| 输入 | `exec` | Exec |
| 输出 | `out1` … `outN` | Exec |

「输出」参数默认 1，范围 1–32；按加号增加、按叉删除，第一个不能删除。
输出引脚画在各参数行右侧，带 `Exec` 徽标和序号。每个 Exec 输出最多一条边；
需要扇出时增加分支。Exec 输入允许多个来源，每次触发都会重新执行。

顺序执行本身固定为同步串行，不提供逐行阻塞开关；分支失败即停止，不执行后续分支。

例如：`起点 → Sequence`，`out1 → 保存 A → 后续处理`，`out2 → 保存 B`。
保存 B 必须等保存 A 及其后续处理全部完成；保存所需的数据另接 Data 线，来源节点需先经 Exec 执行。
