# Set

**id** `set` · **分类** 变量

把数字、文本或布尔值送上执行线，再连接到变量节点的 `Set` 口。
节点本身不保存值，只把输入原样输出。

## 端口

| 方向 | 端口 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `exec` 执行 | Exec | 由执行线触发 |
| 输入 | `value` 变量输入 | `NUMBER` / `TEXT` / `BOOL` | 必填，由「变量类型」参数决定 |
| 输出 | `out` 输出 | `NUMBER` / `TEXT` / `BOOL` | 接到同类型变量节点的 `Set` 口 |
| 输出 | `then` 继续 | Exec | 输入取得并输出后继续执行 |

## 参数

| 控件 | 默认 | 选项 |
| --- | --- | --- |
| 变量类型 | 数字 | 数字 / 文本 / 布尔 |

切换类型时，`value` 和 `out` 会一起变成对应类型。

## 行为约定

- Set 是执行节点：必须由 Exec 触发，成功后沿 `then` 继续。
- 输入值原样传出，包括上游挂着的文件名提示。
- Set 可以接多个变量节点的 `Set` 口；每次执行都会分别写入。
- 它不触发变量读取方，写入在本次运行内生效；成功运行后最终值写回变量参数。

典型连接：

```text
起点 → Set(exec) → 保存(exec)
         ↑ value             ↑ 数据
      运算结果 ──────────────┘
Set.out → 数字变量.Set
```
