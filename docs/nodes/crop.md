# 图像裁切

**id** `crop_image` · **分类** 图像

从图上取出一块：按长宽比取、取固定尺寸，或者把四周的透明留白裁掉。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` PNG 图像 | `Image(Png)`（必填） |
| 输出 | `image` PNG 图像 | `Image(Png)` |

输入输出都锁在 PNG，和「缩放图像」一样 —— 要改用别的格式先接一个「图像格式转换」。
这一步是为了让类型检查在编辑期就是准的。

## 参数

| 参数 | 控件 | 默认 | 何时显示 |
| --- | --- | --- | --- |
| 裁切方式 | 下拉 | 裁切到比例 | 总是 |
| 长宽比 · 宽 | 数字 1–1000 | 16 | 裁切到比例 |
| 长宽比 · 高 | 数字 1–1000 | 9 | 裁切到比例 |
| 宽度 | 数字 1–100000 px | 512 | 裁切到大小 |
| 高度 | 数字 1–100000 px | 512 | 裁切到大小 |
| 保留位置 | 下拉 | 居中 | 裁切到比例 / 裁切到大小 |

**保留位置**有九个锚点：居中、靠上、靠下、靠左、靠右、左上角、右上角、左下角、右下角。
它决定从原图里取走的是哪一块。

## 行为约定

- **裁切到比例**：取一块最大的、符合目标长宽比的区域。原图比目标「更宽」就裁掉左右，
  「更高」就裁掉上下。
- **裁切到大小**：要的尺寸比原图还大时，贴着边取到原图那么大，并给出提示。
- **裁切到内容**：认的是透明通道，四边向内缩到最近的有色像素。
  - 四周没有整块透明的留白时不动它，提示一句原样通过；
  - 整张图都透明时也无从下手，同样原样通过。
  - 半透明（alpha 不为 0）算「有色」。想连半透明一起裁，先把它压成完全透明。
- 裁完会把**来源文件名**接着带下去（和别的图像节点一样），下游「保存到目录」还能用它起名。
- 输出一律是 PNG；和上游一样只保留像素与出处两样东西，别的元信息不会跟过来。

## 实现

`core/src/nodes/crop.rs`，`NodeSpec::fixed`。

裁切矩形由一个 `(x, y, 宽, 高)` 元组算出来，再统一交给 `image::DynamicImage::crop_imm`。
锚点在 `anchored()` 里用两个 0 / 0.5 / 1 的分数表示 —— 左上角是 `(0, 0)`，右下角是 `(1, 1)`，
两端之间就是「还剩多少可以偏」乘以这个分数。

「裁切到内容」扫一遍 RGBA，记下 alpha 不为 0 的像素的外接矩形。
输出一律转成 RGBA8 再编 PNG，这样透明通道的语义在整条路上是一致的。

测试：`crop_to_ratio_keeps_the_target_aspect`、`crop_to_size_anchored_at_a_corner`、
`crop_to_content_trims_the_transparent_border`。
