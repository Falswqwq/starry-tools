# 图像裁切

**id** `crop_image` · **分类** 图像

从图上取出一块：按长宽比取、取固定尺寸、把四周的透明留白裁掉，或者停下来让用户手动框一块。

切到**形状裁切**时，它变成一个**紫色（阻塞）节点**：运行到它会拦住整条链，在屏幕中间
弹出一个模态浮层，摆出图片让你拖一个遮罩框定范围，按「确定」才继续。
见[界面与交互](../interface.md#紫色阻塞节点)。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` PNG 图像 | `PNG`（必填） |
| 输出 | `image` PNG 图像 | `PNG` |

输入输出都锁在 PNG，和「缩放图像」一样 —— 要改用别的格式先接一个「图像格式转换」。
这一步是为了让类型检查在编辑期就是准的。

## 参数

| 参数 | 控件 | 默认 | 何时显示 |
| --- | --- | --- | --- |
| 裁切方式 | 下拉 | 裁切到比例 | 总是 |
| 长宽比 · 宽 | 数字 1–1000 | 16 | 裁切到比例 |
| 长宽比 · 高 | 数字 1–1000 | 9 | 裁切到比例 |
| 宽度 | 数字 1–100000 px | 512 | 裁切到大小 |
| 高度 | 数字 1–100000 px | 512 | 裁切到大小 |
| 保留位置 | 下拉 | 居中 | 裁切到比例 / 裁切到大小 |
| 形状 | 下拉 | 矩形 | 形状裁切 |

**保留位置**有九个锚点：居中、靠上、靠下、靠左、靠右、左上角、右上角、左下角、右下角。
它决定从原图里取走的是哪一块。

## 行为约定

- **裁切到比例**：取一块最大的、符合目标长宽比的区域。原图比目标「更宽」就裁掉左右，
  「更高」就裁掉上下。
- **裁切到大小**：要的尺寸比原图还大时，贴着边取到原图那么大，并给出提示。
- **裁切到内容**：认的是透明通道，四边向内缩到最近的有色像素。
  - 四周没有整块透明的留白时不动它，提示一句原样通过；
  - 整张图都透明时也无从下手，同样原样通过。
  - 半透明（alpha 不为 0）算「有色」。想连半透明一起裁，先把它压成完全透明。
- **形状裁切**：运行时在屏幕中间弹出遮罩浮层，可以整体拖动、也可以拖四个角改大小
  （角把柄很大、悬停会给缩放光标）；按住 `Shift` 锁定为正方形（椭圆模式即正圆）。
  椭圆模式下压暗的是真正的**椭圆之外**，而不是矩形的四条边。按「确定」严格按框内的
  像素裁切 —— 矩形取那一块，椭圆则把轮廓外的像素挖成透明（长宽相等时就是正圆）。
  按「取消」这次运行就失败。遮罩至少留 4 像素，且不会越出图像范围；越界的答案在
  core 里还会被再夹一次。
- 裁完会把**来源文件名**接着带下去（和别的图像节点一样），下游「保存到目录」还能用它起名。
- 输出一律是 PNG；和上游一样只保留像素与出处两样东西，别的元信息不会跟过来。
