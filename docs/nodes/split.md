# 图像分割

**id** `split_image` · **分类** 图像

按透明部分把一张图切成多张。把**不透明**的像素按邻接关系分成一块块，每块裁一个外框、
各成一张图，装成一个 `List[Png]`。sprite 图（一整张拼图里放了很多小图）的常见处理就是它。

输出是列表，所以通常接给「[遍历](iterate.md)」逐张处理。

## 端口

| 方向 | 端口 | 类型 |
| --- | --- | --- |
| 输入 | `image` 图像 | `IMG`（必填） |
| 输出 | `out` 图像列表 | `List[Png]` |

## 参数

| 参数 | 控件 | 默认 | 说明 |
| --- | --- | --- | --- |
| 邻接方式 | 下拉 | 八邻接 | 斜着挨着的像素算不算同一块 |
| 最小像素数 | 数字 | 0 | 比这还小的碎块丢掉（去噪）；0 表示不过滤 |
| 每张留边 | 数字 | 0 | 每张切出来的图四周多留多少透明边 |

## 行为约定

- 透明（alpha = 0）的像素不算内容；不透明的像素按邻接方式连成一块块，每块裁一个外框。
- 结果按**从上到下、从左到右**排（按外框左上角），顺序稳定。
- 输出都是 PNG（带透明通道）。
- 每张图的名字是「原名-序号」—— 下游「保存到目录」写盘时不会互相盖。
- 整张图没有任何不透明像素（或没有透明部分可切）时，原样返回一张图并给出提示。

## 例子

```
读取 (sprite.png) ─ img ─→ 图像分割 ─ List[Png] ─→ 遍历 ─ item ─→ 缩放图像
                                                     └ finally ─→ 保存到目录
```

一张 sprite 图先被切成很多小图，再逐张缩放、保存。
