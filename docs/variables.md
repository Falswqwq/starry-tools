# 变量节点

数字、文本、布尔是节点本地变量，位于节点库「变量」分类，边线为深绿色。
没有全局变量表或变量面板；变量值保存在节点参数里，随工作流一起存档。

| 节点 | id | 本地参数 | Get | Set |
| --- | --- | --- | --- | --- |
| 文本 | `literal_text` | 文本 | `out` | `set` |
| 数字 | `literal_number` | 数字 | `out` | `set` |
| 布尔 | `literal_bool` | 开关 | `out` | `set` |

## Get 与 Set

- 节点没有 `exec` / `then`，不直接参与执行线。
- **Get** 是普通数据输出，可以同时接多个下游。
- **Set** 是数据输入，允许接多条线；上游每产生一次值就写一次，
  按实际运行顺序以后写到的为准。
- Set 不构成 Get 的求值依赖。`Get → 运算 → Set` 不会形成纯数据环；
  运算节点需要由执行线触发后才会把结果写入 Set。
- 没有 Set 写入时使用节点参数中的本地值。
- 运行中的写入先保存在引擎状态里；整个运行成功后，app 把最终值写回节点参数，
  下一次运行从新值开始。失败运行不提交。
- Set 写入本身不会触发任何节点继续运行。

变量节点本身是纯节点，可以被「运行至此」单节点求值。

需要让写入明确排在执行线上时，使用同分类的 [Set](nodes/set.md) 节点：
它接收数字 / 文本 / 布尔中的一种，由 Exec 触发，输出接到变量节点的 Set 口。
运算节点也在这个分类中，同样是显式执行节点。
